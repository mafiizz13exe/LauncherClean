# Prazo Magazord (APK)

App Android que abre todo dia no horário configurado, entra no painel Magazord
e ajusta o "Prazo de Expedição" dos itens do estoque.

Nenhuma credencial fica neste repositório: e-mail, senha e chave do 2FA são
digitados no próprio app e guardados só no celular.

O APK é gerado pelo GitHub Actions (aba Releases, tags `prazo-v*`).
